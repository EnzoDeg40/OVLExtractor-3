Mettre cette carte à jour

La page ne contient aucune connaissance en dur. site/build.py inventorie chaque paire d'OVL avec ovlextract --list-loaders, puis décide de l'état de chaque type de ressource à partir de trois sources : le registre des loaders de docs/RCT3_OVL_FORMAT.md (§2) et les titres de section qui nomment un tag, le code de extractors/src/ (un tag cité dans un extracteur est un tag qu'il traite), et site/annotations.json pour ce que le registre ne dit pas encore.

Après une avancée : la noter dans la doc ou l'écrire dans un extracteur, puis relancer

python3 site/build.py "$ASSETS"      # rescanne l'installation (≈ 10 s)
python3 site/build.py --cached       # docs et code seulement
